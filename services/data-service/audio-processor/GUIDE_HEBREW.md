## הסבר האלגוריתמים — שלב אחר שלב

### אלגוריתם 1: פילטר וינר (`wiener_filter.py`)

**מטרה:** ניקוי רעשי רקע (מזגן, מסדרון, כביש) מההקלטה.

**איך עובד:**
1. לוקח את החצי שנייה הראשונה — ההנחה שזה רק רעש רקע
2. מחשב "טביעת אצבע" של הרעש (באילו תדרים הוא חזק)
3. עובר על כל ההקלטה ומפחית את הרעש בכל תדר בנפרד
4. מה שנשאר = אות נקי יותר

**הנוסחה:**
```
H(f) = max(0, 1 - Noise(f) / Signal(f))
```
- אם האות חזק מהרעש → H קרוב ל-1 → שומרים
- אם הרעש חזק מהאות → H = 0 → מדכאים

---

### אלגוריתם 2: VAD — זיהוי פעילות דיבור (`vad_detector.py`)

**מטרה:** לזהות בכל חלון קטן (25ms) האם מישהו מדבר.

**איך עובד — מנגנון הצבעה:**
מחשב 4 מאפיינים ולכל אחד יש "הצבעה":

| מאפיין | דיבור | רעש |
|--------|-------|-----|
| RMS (אנרגיה) | גבוה ✓ | נמוך |
| ZCR (חציית אפס) | נמוך ✓ | גבוה |
| מרכז ספקטרלי | בינוני-גבוה ✓ | נמוך |
| שטחיות ספקטרלית | נמוכה ✓ | גבוהה |

**אם לפחות 2 מתוך 4 אומרים "דיבור" → הפריים סומן כדיבור.**

**עיבוד-אחר:**
- דיבור קצר מ-300ms → כנראה רעש → מוחקים
- שקט קצר מ-200ms → כנראה הפסקה במשפט → ממלאים

**הספים אדפטיביים** — מחושבים אוטומטית מהנתונים (לא קבועים).

---

### אלגוריתם 3: RMS — מדידת עוצמת קול (`rms_analyzer.py`)

**מטרה:** למדוד כמה חזק הצליל בכל חלון.

**הנוסחה:**
```
RMS = √( (1/N) × Σ(xᵢ²) )
```
- מעלים כל דגימה בריבוע (כדי שערכים שליליים יהפכו לחיוביים)
- מחשבים ממוצע
- מוצאים שורש ← זו העוצמה האמיתית

**סיווג:**
- 🟢 שקט: RMS < 0.02
- 🟡 רגיל: RMS < 0.06
- 🔴 רועש: RMS ≥ 0.06

**המרה לדציבלים:** `dB = 20 × log₁₀(RMS)`

---

### אלגוריתם 4: סיווג אקוסטי MFCC (`audio_classifier.py`)

**מטרה:** להבחין בין סוגי צלילים: שקט / רעש סביבתי / פטפטת / דיבור.

**מה זה MFCC?**
Mel-Frequency Cepstral Coefficients — 13 מספרים שמתארים את
"הצורה" של הצליל. MFCC מחקה את אוזן האדם: רגיש יותר לתדרים
נמוכים ופחות לגבוהים.

**כללי הסיווג:**
1. אנרגיה נמוכה מאוד → שקט
2. ZCR גבוה + MFCC אחיד → רעש סביבתי (מזגן, כביש)
3. אנרגיה נמוכה + MFCC מגוון → פטפטת חלשה (תלמידים לוחשים)
4. אנרגיה גבוהה + MFCC מגוון → דיבור ברור

---

### אלגוריתם 5: זיהוי חפיפת דוברים (`overlap_detector.py`)

**מטרה:** לזהות אם מדבר דובר יחיד או מספר דוברים בו-זמנית.

**3 מאפיינים:**
1. **שונות אנרגיה** (40%) — כשמדברים ביחד, העוצמה קופצת
2. **רוחב פס ספקטרלי** (30%) — ערבוב קולות מרחיב את טווח התדרים
3. **שונות שטחיות** (30%) — שינוי "מרקם" הצליל

**ציון חפיפה:** 0 = דובר יחיד, 1 = חפיפה מלאה
**סף החלטה:** מעל 0.45 = ריבוי דוברים

---

### אלגוריתם 6: ASR — המרת דיבור לטקסט (`context_analyzer.py`)

**מטרה:** להמיר את הדיבור שלפני ריבוי הדוברים לטקסט.

**איך עובד:**
1. שומר את קטע האודיו לקובץ WAV זמני
2. שולח ל-Google Speech API (תומך עברית)
3. מקבל טקסט חזרה
4. מוחק את הקובץ הזמני

**דורש חיבור אינטרנט.** אם אין — מחזיר "לא ידוע".

---

### אלגוריתם 7: NLP — סיווג הקשר פדגוגי (`context_analyzer.py`)

**מטרה:** להבחין בין ריבוי דוברים "טוב" (דיון) לבין "רע" (הפרעה).

**איך עובד:**
- מקבל את הטקסט מ-ASR
- מחפש מילות מפתח: "דיון", "קבוצות", "שאלה", "חשבו" וכו'
- אם נמצאו 2+ מילות מפתח → למידה פעילה
- אם נמצאה 1 → למידה פעילה (ביטחון נמוך)
- אם 0 → הפרעה

---

### אלגוריתם 8: ממוצע משוקלל (`attention_scorer.py`)

**מטרה:** לשלב את כל התוצאות לציון קשב אחד (0-100).

**הנוסחה:**
```
ציון = 0.35 × דפוס_דיבור + 0.25 × רמת_רעש + 0.25 × הקשר + 0.15 × פעילות
```

**ציוני המרכיבים:**

| מצב | דפוס דיבור | רמת רעש | הקשר | פעילות |
|-----|-----------|---------|------|--------|
| דובר יחיד + שקט | 100 | 90 | 50 | 85 |
| דובר יחיד + רגיל | 100 | 80 | 50 | 85 |
| ריבוי + למידה | 70 | 80 | 80 | 85 |
| ריבוי + הפרעה | 20 | 30 | 15 | 85 |

**דירוג שיעור:**
- 80+ = מצוין
- 60-79 = טוב
- 40-59 = בינוני
- מתחת ל-40 = נמוך

## זרימת הצנרת הראשית

```
קובץ שמע (WAV/MP3)
    ↓
[1] פילטר וינר — ניקוי רעשי רקע
    ↓
[2] חלוקה לחלונות של 3 שניות
    ↓  לכל חלון:
[3] VAD — יש דיבור? (כן/לא)
[4] RMS — מה העוצמה? (שקט/רגיל/רועש)
[5] MFCC — מה סוג הצליל?
[6] חפיפה — דובר יחיד או ריבוי?
    ↓  אם ריבוי דוברים:
[7] ASR — תמלול 5 השניות שלפני
[8] NLP — למידה פעילה או הפרעה?
    ↓
[9] ממוצע משוקלל — ציון קשב (0-100)
    ↓
ציון כולל לשיעור + שמירה ב-SQL
```
